# music-player-part-2
Java music player with favorites and playback controls

## How to run
Open the repository in VS Code with Java 21 installed.
Open SpotifyLikeAppExampleCode.java and select Run above main().

## Main menu
- h: Home
- s: Search by song title
- l: List the library, then choose a song number
- f: Show favorites
- q: Quit

## Playback controls
Choose a song from the library first.
- u: Pause or resume
- x: Stop and reset to the beginning
- r: Rewind 5 seconds
- n: Forward 5 seconds
- t: Add or remove the current song from favorites

Favorite choices are saved in audio-library.json and loaded on the next run.
